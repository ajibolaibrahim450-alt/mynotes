## Week 2 - Bits and Bytes
- A bit can be either 0 or 1, and 8 bits make one byte.
- RAM is temporary and loses its data when the computer is turned off, while HDDs and SSDs keep data.
- ASCII assigns numbers to characters, while Unicode supports characters from many different languages.
## Week 3 - Text Structure
- Markdown uses symbols like ## for headings and ** for bold.
- HTML uses tags to organize content on a web page.
## Week 4 - Keyboards and Editors
- Keyboard shortcuts can save time and make editing text easier.
- Word processors, such as Microsoft Word, are different from plain text editors.
## Week 5 - Command Line Interface (CLI)
- A CLI lets us control a computer by typing commands instead of clicking through menus.
- Some of it command are e.g ls - list files, cat - which displays file content
